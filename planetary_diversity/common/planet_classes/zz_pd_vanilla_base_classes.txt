# Main PD owns the vanilla climate base classes so PD variants can carry a distinct UI type-icon via 4.4 conditional_icon.
# A PD variant world is its vanilla base class (e.g. pc_continental) plus a pd_* modifier; conditional_icon swaps only the small type-icon to match the variant, falling back to the vanilla icon when no variant modifier is present.
# Bodies below are VERBATIM 4.4 vanilla; only the conditional_icon blocks are added. Re-sync the bodies every patch.
# vanilla_replacements must NOT also define these classes, or the last-loaded copy wins and clobbers this one.
