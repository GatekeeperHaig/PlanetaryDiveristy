# Picture-only dummy classes for cryophile-owned Domed Colonies, one per (domed variant x atmosphere).
# Used solely as the set_planet_entity picture override; the planet keeps its real pc_pd_domed_colony_* class and its +0.5 tolerance.
# Each keeps the base Domed Colony's entity (the dome model), points at its own custom exotic portrait, and applies the matching exotic color LUT.
# Superhabitable has no dummy here: like the base game, superhabitable reuses the barren portrait (handled in pd_exotic_domed_effects.txt).
# DO NOT USE elsewhere: not in starting sets, terraform options, or habitability.

###Ammonia domed pictures
pc_pd_domed_colony_barren_ammonia = {
	entity = "domed_colony_barren_planet"
	entity_scale = @planet_standard_scale
	icon = GFX_planet_type_barren
	icon_large = GFX_planet_type_barren_big
	picture = pc_pd_domed_colony_barren_ammonia
	atmosphere_color 		= hsv { 0.1 0.15 1.1 }
	atmosphere_intensity 	= 1.1
